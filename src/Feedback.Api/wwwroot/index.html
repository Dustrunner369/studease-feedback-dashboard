How we prioritize

Similar requests are grouped into one problem. We weigh each problem on four things:

  1. Reach: how many people are asking for it.
  2. Pain: how much the problem gets in the way today.
  3. Strategic fit: how well it serves Studease's goals: finding new spots, coming back, the social side.
  4. Retention risk: whether it might make people stop using Studease.
