AI cost log: Studease Feature Intelligence System
Prices are from OpenAI's docs (developers.openai.com) and TypeSafe AI's docs, checked 2026-11-05, Standard tier, USD per 1M tokens.
Token counts per call are planning estimates, not measurements. Replace them with real numbers from the AI call log after the seed-backlog comparison run.

CHOSEN MODELS
- Embeddings (suggest-as-you-type, Problem shortlist): text-embedding-3-small, 1536 dims, $0.02 input
- Small tier (matching, priority scoring, file picker, public wording, Requester update drafts): gpt-6-luna, $0.10 input / $0.50 output
- Large tier (decision brief, Suggest Solutions): gpt-6.1-sol, $2.00 input / $10.00 output

ALTERNATIVES CONSIDERED
- gpt-6-astra (OpenAI's strongest/default): $10.00 input / $50.00 output, about 5x Sol. Rejected as too expensive.
- Jev (TypeSafe AI): $0.042 input / output free. Fits matching only; writes no text, makes no embeddings, gives no written reason. Waitlisted access (the user has a key).

ESTIMATED MONTHLY COST (low traffic: 300 submissions, 20 briefs, 20 Suggest Solutions runs, 200 emails)
- Matching: Luna ~$0.07 vs Jev ~$0.02 (about 5 cents/month difference)
- At 100,000 submissions/month, matching would be ~$22 with Luna vs ~$6 with Jev
- Briefs + Suggest Solutions: Sol ~$3.50/month vs Astra ~$17/month
- Priority scoring: ~$0.10/month (one call per submission plus re-scores on moves, merges, splits and criteria saves)
- Everything else: pennies

ESTIMATED COST PER SEED LOAD (~150 Feature Requests through the real pipeline)
- Per request: embedding (~$0.000002) + Luna matching (~$0.0002) + Luna priority scoring (~$0.0003) = ~$0.0005
- Whole load: ~$0.08, plus a few cents of re-scores from the pre-set product-team actions. Re-seeding during the build is effectively free.

ESTIMATED COST PER CONSISTENCY CHECK (Metrics panel "Run consistency check")
- Every open Problem re-scored 3 times with Luna: ~15 Problems x 3 x ~$0.0003 = ~$0.01 per run. Saved Recommended Priorities are not changed.

TALKING POINTS: WHY NOT JEV FOR MATCHING
- At this traffic, Luna costs about 5 cents a month more than Jev.
- What Luna buys: a written reason for every matching decision (observability), one vendor and key, the official OpenAI .NET library, and one consistent AI log.
- What it gives up: Jev's lower cost (only significant at very high volume) and probably its speed (TypeSafe claims 70-500 ms, from its own benchmarks).
- At high volume, Jev becomes a candidate for matching, with the reason coming from somewhere else.

CAVEATS
- OpenAI lists no dated version IDs for GPT-6 models, so models can't be pinned; the AI log records the exact model name the API reports on each call.
- Prompts over 272K input tokens cost 2x input and 1.5x output (not expected here).
- OpenAI's Batch API is 50% off, relevant only if processing moves to scheduled batches at high volume.
- Luna's cached-input price differs between two OpenAI pages ($0.01 vs $0.10); not material here.
- Temperature: only accepted when reasoning effort is none (gpt-6-luna). gpt-6.1-sol never accepts it. No seed on the Responses API, so AI ratings can't be made fully repeatable (OpenAI latest-model guide, checked 2026-11-05).
